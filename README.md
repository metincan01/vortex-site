# Vortex

Vortex için hazırlanmış, GitHub Pages üzerinde yayımlanmaya hazır Türkçe tanıtım sitesi.

## Özelleştirme

- `index.html` içindeki metinleri şirketinizin gerçek hizmetlerine göre düzenleyin.
- İletişim bölümündeki `hello@vortex.com` adresini kendi e-posta adresinizle değiştirin.
- Renkleri `styles.css` dosyasının başındaki CSS değişkenlerinden güncelleyin.

## GitHub Pages

Depoyu GitHub'a yükledikten sonra **Settings → Pages → Deploy from a branch** seçin ve `main` dalının `/ (root)` klasörünü yayımlayın.
